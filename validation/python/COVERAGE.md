# Coverage — python.md

This file records the evidence behind `skills/objectbox/references/python.md`, the Python reference
of the ObjectBox skill.
Every statement there about how ObjectBox behaves in Python is traced here to an upstream test,
the library source or a recorded run, or it is marked as unverified.
This repository holds no tests of its own: the evidence lives in objectbox-python's test suite,
and what it does not assert is added there.

The main table has one row per row of the skill file's "Quick reference — common mistakes" table,
with the first column copied verbatim; `../check_coverage.py` fails when the two tables drift apart.
The claims were verified against objectbox-python **5.0.0** (`requirements.txt`: `objectbox-sync`,
so the Sync snippets run; native library objectbox-sync-clib 5.3.2) on Linux x64, on 2026-10-19,
using objectbox-python commit `4f12cc2` (package version 5.0.0b2), before the `v5.0.0` tag existed;
before with commits `f0a0588` and `b1dec39` (2026-10-19), `d51718e` (2026-10-18) and first `be7e37b` (2026-10-14).
Until that tag is pushed, `../check_upstream.py --binding python` fails at the pinned tag;
run it against a local checkout:
`run.sh --repo objectbox-python=<checkout> --ref 4f12cc2` (with `PYTHON` set to an interpreter
that has that build installed).

The Upstream column cites tests as `tests/<file>.py::<test function>` in
[objectbox-python](https://github.com/objectbox/objectbox-python).
`../check_upstream.py --binding python` resolves every such locator at the pinned tag and shows
which cited tests changed on a pin bump.
A locator is only written after reading the test body; a grep hit is a candidate, not evidence.

"Recorded run" means a script run against a 5.0.0 release candidate (2026-10-14 or 2026-10-18),
with its output quoted; it is evidence until an upstream test asserts the same.

Status values:

- `verified <version>`: an upstream test or the library source at that version proves it.
- `partial`: the recipe is proven, the failure mode is not (or only by a recorded run).
- `manual`: the evidence is the library source, a docs page or a recorded run, named in the row.
- `unverified`: nobody has run it; treat the skill text as a hypothesis.
- `opinion`: an architecture rule, not falsifiable.
